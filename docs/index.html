⚡ 7 High-Speed Pipeline Stages (<200ms P50)
Each stage is optimized with hardware acceleration, retry backoffs, and strict grounding:
Stage 1 · Speech-to-Text
🎙️ Multi-Provider STT
Dual provider resilience: Sarvam AI (saarika:v1) for Indian accents with instant Groq Whisper Turbo cloud fallback.
Latency: ~65ms
Stage 2 · Security
🛡️ Input Guardrails
Deterministic filters block prompt injections, jailbreaks (e.g. "system override"), and toxic payloads before vector search.
Latency: ~12ms
Stage 3 · Context
🧠 Conversational Memory
Tracks multi-turn turns across sessions; autonomously rewrites pronoun queries ("What are its types?") with subject context.
Latency: ~5ms
Stage 4 · Vector DB
🔍 FAISS Dense Retrieval
Searches 48,995 chunks across 4 chunking strategies in 384 dimensions using Inner-Product Cosine Similarity.
Latency: ~45ms
Stage 5 · Generation
⚡ Groq LPU Inference
Runs groq/compound-mini with strict context grounding, Pydantic schema validation, and 3 follow-up suggestions.
Latency: ~80ms
Stage 6 · Quality Audit
🔍 Hallucination Check
Calculates semantic cosine similarity between the generated answer and retrieved passages to verify factual accuracy.
Latency: ~10ms
✂️ 4 Multi-Strategy Chunking Paradigms
Instead of naive fixed chunking, MSMARCO-XI is split across 4 complementary strategies:
1. Fixed-Size Overlapping
256 token windows with 20% sliding overlap to prevent broken sentences and word splits across chunks.
2. Sentence Boundary
Splits strictly along punctuation boundaries preserving grammatical and syntactic integrity.
3. Paragraph-Aware
Splits documents according to visual structure and conceptual paragraph boundaries.
4. Semantic Similarity
Embeds adjacent sentences and splits when cosine similarity drops below threshold to ensure topical coherence.
